## Problem Idea

This project aims to analyze whether students’ study habits and attendance can help predict their academic performance. Using a small educational dataset, the project demonstrates the basic steps of data analysis and machine learning, including data preparation, exploration, and prediction.

## Current Dataset Status

A sample student dataset is used for initial data exploration and laboratory activities. Basic data inspection and analysis have already been performed. More datasets can be included in later stages to further improve the analysis.

## How to Run the Notebook

1. Clone the repository.
2. Install the required packages listed in `requirements.txt`.
3. Open the notebook located in the `notebooks` folder.
4. Run all cells in Google Colab or Jupyter Notebook.

## Preliminary Results

The current results are preliminary and mainly used for learning and experimentation. The project is still in progress, and the results may be updated as more data and different machine learning models are evaluated.
